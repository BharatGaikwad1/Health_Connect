# Premium UI Skills Enforcement

When you are asked to design, build, or review user interfaces, you MUST leverage the installed design skills in the workspace to ensure the UI is premium and avoids generic "AI slop". 

Specifically, actively consult and apply the guidelines from:
1. **impeccable** - For overall design vocabulary, visual polish, and aesthetic layout.
2. **design-taste-frontend** - For anti-slop frontend layouts, modern layout standards, and robust component hierarchies.
3. **emil-design-eng** - For deep UI polish, smooth animations, and invisible details that make interfaces feel natural and responsive.

Never output basic or unstyled MVP UI. Always aim for rich, production-grade aesthetics using the guidelines provided by these skills.
